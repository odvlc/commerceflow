# Project file guide

Each maintained file is listed with its purpose and maintenance notes. Inline comments explain
responsibilities and non-obvious invariants without changing executable behavior. Formats that
cannot safely contain comments are documented here.

Generated builds, downloaded dependencies, caches, live credentials and IDE metadata are outside
this inventory. Existing upstream Maven launchers retain their original documentation. Applied
Flyway migrations, versioned prompts, retrieval fixtures and retained evaluation evidence are
documented here with their bytes preserved. Strict JSON files have no added comment fields.

For architectural requirements see [the specification](../CODEX_PROMPT.md); for commands/results and
remaining acceptance requirements see [PLAN.md](../PLAN.md) and [AI_PLAN.md](../AI_PLAN.md).
